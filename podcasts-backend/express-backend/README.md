# Express backend — Audio Player

## Что изменено

`data/tracks.js` теперь содержит настоящие тестовые аудиоданные в поле `encoded_audio`.

Каждое значение имеет формат:

`data:audio/wav;base64,...`

Это валидный PCM WAV (8 kHz, mono, 8-bit), сгенерированный специально для тестирования
аудиоплеера. У каждого трека/подкаста своя тональность, поэтому можно отличать записи
при воспроизведении.

Длительность тестовых аудио — 12 секунд. Этого достаточно для проверки:

- play / pause;
- следующего и предыдущего трека;
- перемотки по шкале;
- `-10` / `+10` секунд;
- окончания трека и автоматического перехода.

## Запуск

```bash
npm install
npm start
```

Сервер запускается на `http://localhost:8000`.

API доступен через `http://localhost:8000/api`.
